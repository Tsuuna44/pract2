# depgraph — визуализация графа зависимостей пакетов Cargo 

## 1. Общее описание

**depgraph** — это CLI-инструмент на языке Python, предназначенный для построения и визуализации графа транзитивных зависимостей пакетов из реестра **Rust (Cargo)**.

Инструмент позволяет:
- Получать информацию о прямых и транзитивных зависимостях заданного пакета.
- Работать в двух режимах: `real` (запрос к реальному реестру `index.crates.io`) и `test` (чтение локального файла-графа).
- Находить циклические зависимости.
- Строить обратные зависимости (кто зависит от заданного пакета).
- Выводить граф в виде текста (списки смежности), ASCII-дерева и диаграмм **Mermaid**.
- Генерировать PNG-изображение графа с помощью сервиса `mermaid.ink`.

*Проект выполнен в рамках дисциплины «Конфигурационное управление» (Вариант 14).*

## 2. Описание всех функций и настроек

Инструмент настраивается исключительно через **опции командной строки**.

| Опция | Аргумент | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `-p`, `--package` | `<имя>` | **Обязательный.** Имя анализируемого пакета. В режиме `test` — только заглавные латинские буквы (например, `A`). | — |
| `-r`, `--repo` | `<url/путь>` | Источник данных. В режиме `real` — URL реестра. В режиме `test` — путь к файлу описания графа. | `https://index.crates.io` |
| `-m`, `--mode` | `real` \| `test` | Режим работы. `real` — анализ реального реестра Cargo. `test` — анализ локального файла. | `real` |
| `-t`, `--tree` | — | Флаг. Выводит граф в виде ASCII-дерева с пометками циклов и повторяющихся узлов. | выкл. |
| `--reverse` | — | Флаг. Выводит **обратные** зависимости (кто зависит от пакета). *Работает только с `--mode test`.* | выкл. |
| `--mermaid-out` | `<путь>` | Путь к файлу, куда будет сохранен текст диаграммы Mermaid. | `graph.mmd` |
| `--no-image` | — | Флаг. Отключает генерацию и открытие PNG-изображения. | выкл. |

### Структура проекта
- `src/` — исходный код (разбит по этапам `etap1.py` ... `etap5.py`).
- `tests/` — тестовые файлы-графы (`graph.txt`, `cycle.txt`, `diamond.txt`).
- `Makefile`, `run.sh`, `run.bat` — скрипты для запуска.

## 3. Описание команд для сборки проекта и запуска тестов

Проект не требует установки внешних зависимостей, кроме стандартной библиотеки Python (версия 3.10+).

### Запуск программы
Из корня репозитория:
```bash
# Тестовый режим (используя файлы из папки tests)
python src/etap5.py -m test -r tests/diamond.txt -p A -t --no-image

# Реальный режим (запрос к crates.io)
python src/etap5.py -p serde -t --no-image
